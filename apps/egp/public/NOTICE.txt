ระบบเชื่อมโยงข้อมูลจัดซื้อจัดจ้างภาครัฐ - E-GP portfolio demonstration

Announcement, synchronization and email report page markup adapted from the
owner-provided PHP application. The dashboard, neutral navigation shell and
browser-only behavior were created for the portfolio. No original PHP service,
database configuration, directory authentication, logos, logs or workers ship
with this static demonstration.

The initial dataset contains exactly 100 announcements and 10 queues. Agency
names and organizational branding were replaced. Announcement descriptions,
project IDs, dates and public document/contract links match their source records.
Public links open the external E-GP website only when clicked. Internal system
connection details are excluded. Changes are stored only in the current browser tab.
Synchronization and email actions are simulated and do not contact the source.
