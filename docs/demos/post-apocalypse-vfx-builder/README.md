# Post-Apocalypse VFX Builder v4

## สิ่งที่แก้
- ปรับ `Ground Shadow` ให้เห็นผลชัดขึ้นแล้ว
- เพิ่ม preset library จำนวนมากขึ้น โดยแต่ละหมวดมีประมาณ 8–9 preset

- Oil Fire
- Flamethrower Stream
- Molotov Ignite

- Engine Fire
- Fire Burst
